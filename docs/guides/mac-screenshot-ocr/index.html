Mac 截图怎么打码和提取文字？

按 ⌃⌘A 框选截图，用 M 添加马赛克或 B 实心遮挡。按 X 在本机识别中英文，选中文字后按 ⌘C 复制。

框选、遮挡和导出

  1. 在 macOS 14 或更高版本打开 DeskKit，在「系统设置 → 隐私与安全性」授予屏幕录制权限，再重新启动 DeskKit。
  2. 按 ⌃⌘A 启动截图。点击选中建议的窗口区域，或拖动鼠标自定义选区。
  3. 按 M 画马赛克，或按 B 画实心遮挡，覆盖你想隐藏的区域。
  4. 检查选区和遮挡范围，在工具栏复制或保存 PNG。

复制截图里的文字

在截图工具中按 X 开始识别。拖动选中需要的文字，再按 ⌘C；按 ⌘A 可全选识别结果。分享复制的文字前，检查其中是否含有敏感信息。

OCR 在 Mac 本机运行，支持中文和英文。
